# Vestra Intel operating model

Vestra Intel is a public-record and authorized-data intelligence system. It looks for economic value in discrepancies and relationships across independent sources rather than assuming that a single database record is enough.

Core pipeline:

public/authorized source -> normalize -> entity resolution -> cross-source discrepancy -> commercial inference -> anomaly -> case resolution -> economics -> next-best research -> evidence feedback -> human review.

Examples of useful joins:

- dissolved company + unclaimed property + surviving IP;
- bankruptcy distribution + dissolved creditor + documented successor;
- unclaimed royalty status + matching ISRC + publisher/rightsholder metadata;
- lapsed patent + independent current commercial activity;
- public surplus record + verified claimant/successor evidence;
- old government contract + new procurement notice + incumbent/award history.

The system optimizes for evidence quality, lawful monetization path, time-to-value, regulatory friction, and research cost.
