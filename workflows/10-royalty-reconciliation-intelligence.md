# Workflow 10 — Music Royalty Reconciliation Intelligence

1. Import a public SoundExchange unclaimed-status list/export.
2. Import MLC data only through authorized Data Program access.
3. Normalize ISRC, work title, writer, publisher, artist and sound-recording-owner identifiers.
4. Resolve exact identifiers before fuzzy names.
5. Flag cross-system discrepancies such as an unclaimed SoundExchange status plus MLC metadata for the same ISRC.
6. Validate the discrepancy manually before delivering a client report.
7. Monetize the reconciliation/audit service, not the underlying third-party royalty.
8. Never submit a royalty claim or change ownership shares without the lawful rightsholder's authorization and the applicable platform process.
