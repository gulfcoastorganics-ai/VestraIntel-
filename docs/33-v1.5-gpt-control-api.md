# v1.5 GPT Control API

v1.5 makes ChatGPT/custom GPTs a first-class front end for FIA while keeping the intelligence database and source scheduler in the backend.

## Public setup endpoints

- `GET /health` — hosting health check.
- `GET /gpt/openapi.json` — GPT Action schema generated with the configured public HTTPS origin.
- `GET /privacy` — privacy-policy page suitable for a private GPT and as a starting point for public publication. Add a real operator contact before public distribution.

## Authenticated GPT endpoints

All `/agent/*` routes require `Authorization: Bearer <FIA_AGENT_API_KEY>`.

Read surfaces:

- `/agent/status`
- `/agent/portfolio`
- `/agent/opportunities`
- `/agent/cases/{anomaly_id}`
- `/agent/review-ready`
- `/agent/source-candidates`
- `/agent/portal-candidates`

Analysis/discovery:

- `POST /agent/analyze`
- `POST /agent/discover-sources`
- `POST /agent/discover-portals`

Bounded execution:

- `POST /agent/refresh` — `execute=false` by default.
- `POST /agent/research` — `execute=false` by default and only FIA's read-only whitelist can execute.
- `POST /agent/portfolio-cycle` — both execution flags default false.

Analyst-state changes:

- source candidate state;
- portal candidate state;
- anomaly review state.

No GPT endpoint exists for claimant outreach, claim filing, assignment signing, asset purchase, CAPTCHA bypass, or legal entitlement decisions.

## Deployment security

Set a strong `FIA_AGENT_API_KEY` before exposing the service to the internet. Once configured, `/`, `/api/*`, and `/agent/*` fail closed without the bearer credential. The health, GPT schema, and privacy endpoints remain public.

Set `FIA_PUBLIC_BASE_URL` to the final HTTPS origin so the generated GPT Action schema points at the correct server.
