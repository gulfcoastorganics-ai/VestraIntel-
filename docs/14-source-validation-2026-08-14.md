# Source Validation — 2026-08-14

Official sources revalidated for v0.4:

- California State Controller — investigator/asset-locator fee may not exceed 10% of returned property; owners can claim directly for free.
  - https://sco.ca.gov/upd_investigator_about.html
  - https://www.sco.ca.gov/upd_download_property_records.html
- New York Office of the State Comptroller — location-service provider maximum fee is 15%; quarterly owner file is delivered through secure download and excludes amounts/TINs.
  - https://www.osc.ny.gov/unclaimed-funds/resources/location-service-providers
- U.S. Courts / bankruptcy courts — unclaimed bankruptcy funds remain payable to a party proving entitlement; multiple federal courts recognize successor claimants arising from assignment, purchase, merger, acquisition, or succession and require chain-of-ownership/transfer evidence.
  - https://www.uscourts.gov/court-programs/bankruptcy/unclaimed-funds-bankruptcy
  - https://www.ohsb.uscourts.gov/unclaimed-funds
  - https://www.canb.uscourts.gov/case-info/unclaimed-dividends/instructions-submitting-application-unclaimed-dividends
- Companies House — company profile data exposes previous company names and registered-office information; API access requires authentication.
  - https://developer-specs.company-information.service.gov.uk/companies-house-public-data-api/resources/companyprofile?v=latest
  - https://developer.company-information.service.gov.uk/get-started

These rules are encoded only as triage metadata and hard gates. Production action still requires case-specific legal/compliance review.
