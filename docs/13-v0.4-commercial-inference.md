# v0.4 — Commercial Opportunity Inference

v0.4 converts discovery records and the v0.3 evidence graph into **research triage cases**. It does not establish ownership, entitlement, legal representation authority, or permission to contact anyone.

## Scoring dimensions

Each opportunity receives separate component scores for:

- known value magnitude;
- entity/identifier confidence;
- independent source corroboration;
- recoverability/commercial lane clarity;
- time-to-money proxy;
- regulatory friction;
- acquisition/assignment potential; and
- official-source quality.

The engine stores both a `commercial_score` and an `actionability_score`. Actionability is reduced by unresolved hard gates such as owner agreements, operator registration, jurisdiction review, chain-of-ownership documentation, title review, or insufficient identity corroboration.

## Monetary estimates

The engine only calculates a `gross_fee_ceiling` when both of these are known:

1. the source record contains a face value; and
2. a current official rule validated for that source supplies a percentage fee ceiling.

For v0.4 this applies to California (10%) and New York (15%). New York's quarterly provider file intentionally omits amounts, so most imported New York records will have no monetary fee estimate until a value is lawfully established through the owner/claim process.

A fee ceiling is **not expected revenue** and is not a representation that a contract is enforceable or a claim will be paid.

## Evidence graph enrichment

Companies House source records can now produce:

- `previous_company_name_of` relations from official previous-name fields; and
- `registered_office_at` relations from official registered-office fields.

Addresses are corroborating evidence only. Shared addresses never automatically merge organizations.

## Commands

```bash
fia resolve
fia infer
fia commercial --min-score 60
fia entity-commercial --min-sources 2
fia case 123
```

## Hard boundary

The software remains discovery/research infrastructure. Outreach, assignments, purchases, claims, court filings, and representation are never automated.
