# v1.1 Live Source Orchestration

FIA v1.1 separates **source freshness** from **case research**. Sources have independent modes, cadence policy, access requirements, cursor state, retries, and audit events.

## Modes

- California SCO: weekly bulk ZIP/CSV refresh, Thursday-oriented.
- Companies House: bounded real-time stream catch-up using a dedicated stream key and persisted `timepoint`. Only dissolved/ceased company profile events become discovery records.
- FLC licensing notices: public page polling; FIA's 12-hour check interval is an operator policy, not a claimed FLC publication schedule.
- UK Bona Vacantia estates: periodic public-file polling.
- USPTO Official Gazette: latest Tuesday patent OG notices.
- USPTO ODP: registered but disabled for autonomous refresh until an authenticated product-specific query is configured.

## Safety / compliance

Source orchestration is read-only. It never submits claims, contacts owners, purchases rights, bypasses CAPTCHA, or makes entitlement determinations. Dry-run is the CLI default.

## Retry and audit

Each attempt records source, cursor before/after, counts, result, error, and next due time. Failures use bounded exponential backoff.

## Portfolio allocator

`fia portfolio-run` refreshes due sources first, rebuilds the intelligence graph through the existing scheduler pipeline, then chooses the highest-economic-value permitted research action across all cases. Source execution and research execution require separate explicit flags.
