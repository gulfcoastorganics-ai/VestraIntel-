# v0.2 Data Ingestion and Change-Tracking

## California public bulk records

The California State Controller publishes the public unclaimed-property database as downloadable CSV archives and states that the files are updated every Thursday. The engine supports both direct public download and local ZIP/CSV ingestion. The default live bucket is `$500 and up` so discovery can start with higher-value records without downloading the complete statewide archive.

Commands:

```bash
fia ingest california --bucket 500_plus
fia ingest california-file /path/to/04_From_500_To_Beyond.zip
```

Discovery does not establish entitlement. California's Controller describes investigators/asset locators as third parties who may assist an apparent owner or heir and states that covered fees generally may not exceed 10% of property returned. The engine therefore marks California records `agreement_and_law_review` and does not automate claimant outreach or filings.

## New York owner-name file

New York's Office of Unclaimed Funds provides location service providers a quarterly zipped delimited owner-name file after an online request. The file contains owner names, last-known addresses, property nature, reporting holder and reporting date, but does not include dollar values or taxpayer IDs. The engine deliberately does **not** automate or bypass that request/secure-download process.

After legitimately obtaining the file:

```bash
fia ingest new-york-file /path/to/owner-file.zip
```

New York records are marked `agreement_required` because current OSC procedures require an owner agreement and cap provider fees at 15%.

## Companies House dissolved-company enrichment

Companies House exposes live company data through an authenticated public API. v0.2 adds dissolved-company search, date-range dissolved-company search, company profiles and filing-history retrieval. This branch is read-only intelligence and requires `COMPANIES_HOUSE_API_KEY`.

```bash
export COMPANIES_HOUSE_API_KEY='...'
fia company dissolved-search 'example technology'
fia company dissolved-range 2026-08-01 2026-08-14 --location London
```

The purpose is to correlate dissolved entities with patents, licensing notices, unclaimed property, trademarks, contracts and other surviving assets. Acquisition of bona vacantia property remains a separate legal transaction.

## Source-run audit trail

Every CLI ingestion run now records source, timestamps, status, record count and errors in SQLite. Use:

```bash
fia runs
```

API endpoints:

- `GET /api/runs`
- `GET /api/joins`

The run log provides provenance for future scheduled monitoring and makes failed/stale source adapters visible instead of silently degrading.

## Change detection

Each normalized opportunity receives a stable content fingerprint excluding ingestion timestamp and score. Re-ingestion is classified as:

- **new** — first observation of `(source_id, external_id)`;
- **changed** — a previously seen source record changed materially;
- **unchanged** — the record was seen again with the same source content.

Review deltas with:

```bash
fia changes --limit 50
```

or `GET /api/changes`. This is the basis for scheduled monitoring of weekly California files, quarterly New York files, USPTO/FLC notices, dissolved-company status and future royalty/contract sources.
