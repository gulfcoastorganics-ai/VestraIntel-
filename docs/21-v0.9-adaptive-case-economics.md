# v0.9 — Adaptive Case Economics

## Goal

v0.8 selected the next research lookup by expected information value (EVI). v0.9 adds an independent economic lens so scarce research time can be allocated toward cases where a successful lookup is more likely to matter commercially.

This is a planning system. It does not predict guaranteed revenue and it does not establish legal entitlement.

## Case economics

Each active anomaly receives a `case_economic_states` row containing:

- commercial lane;
- economic status;
- revenue reference, currency, and basis;
- case viability probability;
- planning assumption for time-to-value;
- time discount;
- regulatory-friction factor;
- probability/time/regulation-adjusted expected case value;
- recommended finite research budget;
- best pending task by economic score; and
- the full assumption set used in the calculation.

## Revenue basis hierarchy

The engine deliberately distinguishes fact from assumption.

### `verified_fee_ceiling`

Used only when the underlying official source rule and the property amount provide a calculable maximum service fee. Current examples are California and New York location-service records when a value is actually known.

This is a ceiling, not expected revenue.

### `unknown`

Used when the public record does not disclose enough value information. The engine does not invent a dollar value merely to rank the case.

New York's downloadable location-provider list is an important example: the official file omits dollar amounts.

### `planning_assumption:intelligence_sale`

For an intelligence-only case with no underlying asset value, the engine can use an analyst-supplied notional project value. The default is `$250`, exposed through the CLI and returned in the case assumptions.

### `planning_assumption:capture_rate`

For successor-claim/acquisition/legal-review lanes, face value is not revenue. If a known face value exists, the engine may apply an analyst-supplied capture-rate assumption (default `5%`) solely to create a comparable research-priority reference. It is visibly labeled as an assumption.

## Task economics

Pending tasks receive:

- `resolve_probability`;
- `research_cost`;
- `time_discount`;
- `expected_incremental_value` when a legitimate monetary reference exists;
- `economic_score`;
- eligibility; and
- a JSON rationale containing every assumption.

The probability estimate combines task uplift, task confidence, access mode, blocker coverage, and estimated effort. It does not claim that a public database lookup has a real-world success probability known to that precision; it is a consistent internal ranking heuristic.

## Time and cost

Default time-to-value assumptions are intentionally editable:

| Lane | Default days |
|---|---:|
| intelligence sale | 14 |
| locator service | 45 |
| owner entitlement | 60 |
| successor claim review | 90 |
| legal review | 90 |
| asset acquisition review | 120 |

These are planning assumptions, not service-level promises. New York's Office of Unclaimed Funds says most direct claims are paid within 30 days, but a commercial locator workflow adds owner identification, agreement, documentation, and other uncertainty, so FIA does not equate the state's claimant statistic with a locator turnaround guarantee.

Default research cost is based on effort hours × a configurable analyst hourly cost (`$25/hour` by default) plus modest access/review cost assumptions. Use:

```bash
fia economics --hourly-research-cost 40
```

## Adaptive research budget

A case's recommended research budget increases with its probability-adjusted expected value and commercial score, but is hard-capped. This prevents low-value cases from consuming the same research budget as a materially larger case while still preserving a minimum discovery budget.

## Workflow

```text
public evidence
   ↓
commercial assessment
   ↓
anomaly
   ↓
case target + EVI research queue
   ↓
adaptive case economics
   ├── revenue basis
   ├── viability
   ├── time discount
   ├── regulatory friction
   └── research cost
   ↓
next-economic-lookup
   ↓
human review / permitted official research only
```

## Hard boundary

Economic rank never clears legal gates. A high economic score cannot remove requirements such as:

- proof of ownership/entitlement;
- chain-of-ownership documentation;
- licensing/registration;
- owner authorization;
- title/assignment review;
- court-specific requirements; or
- human approval before outreach, contracting, acquisition, filing, or claiming.
