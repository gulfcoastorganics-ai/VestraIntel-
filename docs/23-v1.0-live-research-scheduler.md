# v1.0 Live Research Scheduler

The v1.0 scheduler closes the loop between adaptive case economics and approved read-only research.

## Execution boundary

Automatic execution is limited to Companies House read-only API tasks already represented in the research catalog. The scheduler never performs claimant outreach, legal filing, asset purchase, claim assignment, CAPTCHA bypass, MLC enrollment access, USPTO credential work without credentials, or entitlement decisions.

## Stop states

- `review_ready`: research target satisfied; human review remains.
- `economically_exhausted`: no permitted automatic task clears economic thresholds/budget.
- `access_blocked`: a permitted automatic task needs a missing credential or a source call failed.
- `human_gate`: remaining useful work is manual/legal/CAPTCHA/enrollment gated.
- `max_steps_reached`: configured execution limit reached.
- `dry_run_complete`: selected the best permitted task without external execution.

## Budgeting and rate control

Each selected task consumes the planning research cost from the v0.9 economics layer. A per-run planning-cost ceiling and maximum step count prevent unbounded loops. Companies House calls are conservatively throttled to at least 0.60 seconds apart by default, below the official default ceiling of 600 calls per five-minute window.

## Usage

```bash
# Plan only (default)
fia scheduler-run

# Execute whitelisted read-only tasks
COMPANIES_HOUSE_API_KEY=... fia scheduler-run --execute --max-steps 20 --max-planning-cost 250

fia scheduler-runs
fia scheduler-run-detail 1
```
